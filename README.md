# NovaVault Demo

NovaVault Demo — це оригінальний **demo/mock** вебінтерфейс преміального крипто-гаманця для портфоліо, презентацій та локального використання.

## Важливо
- Це тільки **DEMO WALLET**.
- **Mock Interface**.
- **Not a real financial service**.
- Без реальних транзакцій, без blockchain API, без справжніх wallet connections.

## Що всередині
- Mobile-first UI у темній fintech-стилістиці.
- Екрани: Wallet, Activity, Portfolio, Settings.
- Splash screen + мікроанімації + таббар.
- Demo-функції Send / Receive / Swap / Buy через модальні вікна.
- Animated demo QR у Receive.
- Локальне збереження state у `localStorage`.
- Генерація випадкового demo-портфеля.

## Локальний запуск
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
